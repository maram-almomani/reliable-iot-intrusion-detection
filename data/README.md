# Dataset

This project uses the IoTID20 dataset for IoT network intrusion detection.

The raw dataset is not included in this repository due to file size and distribution considerations.

## Dataset Scope

IoTID20 contains network traffic representing benign activity and multiple attack categories in an IoT environment.

The project uses the dataset to investigate:

- IoT network intrusion detection
- Feature selection
- Classification performance
- Computational efficiency
- Probability calibration and prediction reliability

## Data Handling

Preprocessing and dataset splitting are performed programmatically to support reproducibility and to reduce the risk of data leakage.

Detailed preprocessing steps will be documented as the experimental pipeline is developed.
